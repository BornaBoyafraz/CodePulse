ℹ How it works
  • CodePulse mines the full commit history of any public GitHub repo using PyDriller, extracting churn, coupling, authorship, and complexity signals per file.
  • An XGBoost model trained on past commit patterns — with a strict temporal split to prevent data leakage — predicts each file's probability of appearing in a bug-fix commit within the next 30 days.
  • SHAP values explain every risk score, showing exactly which signals are driving the prediction for each file.
