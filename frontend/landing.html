How It Works

Three steps from a repo URL to a full risk map.

1

Point it at any GitHub repo

Paste any public GitHub repository URL. CodePulse extracts the full commit history — no installation, no API key, no setup required.

2

ML analyzes years of commit history

An XGBoost model trained on historical patterns — with a strict temporal split to prevent data leakage — scores every file across 10+ engineered risk signals.

3

Get a ranked risk map with plain-English explanations

Every file gets a 0–100 risk score. SHAP values break down exactly which signals drive each prediction — so you always know why a file is flagged.

What CodePulse Detects

Four proven signals — extracted directly from your commit history.

🔁

Code Churn

Files that change constantly are statistically more likely to introduce bugs. CodePulse tracks rolling churn windows (30, 60, 90 days) and spike ratios.

👥

Bus Factor

Files dominated by a single author carry hidden fragility. Low author diversity is a single point of failure — and a reliable predictor of future breakage.

🔗

File Coupling

Files that always change together share risk. CodePulse models co-change patterns as a graph network and propagates risk across tightly coupled clusters.

📈

Complexity Trends

Rising cyclomatic complexity without matching coverage is a reliable failure signal. CodePulse tracks complexity growth over time using Radon analysis.

Not Static Analysis. Temporal Prediction.

Most code tools read what your codebase looks like right now. CodePulse reads the history of how it has evolved — the full record of changes, failures, and patterns over time. Failure lives in the past, not the present state. CodePulse predicts rather than reacts, so you can act before the bug is written.
